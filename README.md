# DHIS2 school inspection

This is a short overview of the project, but you will find a more detailed description of the application in the readme-file in the folder "dhis2_school_inspection". There you will find a description that will give you a detailed explanation of the application both technically and functionally. 

Project Overview

This project was developed as part of a course to address the challenges faced by school inspectors in Edutopia. The goal was to digitize school inspection workflows using a web based application built on the DHIS2 platform to improve data collection, reporting, and resource management.


The Case

Schools in Edutopia face significant challenges such as resource shortages, inconsistent data collection methods, and delays in reporting. This application supports school inspectors by streamlining their work processes, enabling better feedback to head teachers and facilitating resource planning. 


Features: 

1. Data Collection Interface:
  - Record and validate essential school inspection data
    
2. Feature 2: Record a New School:
  - Inspectors can document newly identified schools, including location and basic details.
    
3. Feature 7: School Management Report:
  - Generate dashboards with performance indicators and comparative insights to help head teachers prioritize improvements.
